# South-polar terrain screening: provenance and limits

The optional terrain screen uses `dem_400m.bin.gz` (SHA-256 `71d285a32a4c1410ffed5c4d8bc62ea8ed04625f443d6f72997fa5d8b0208dbf`), from the MIT-licensed [Lunar Horizon / CLPS-MOON-BROWSER](https://github.com/localizedprojects/CLPS-MOON-BROWSER/tree/9801046af387d40cc77db4f0557c802ad8cee5b4/app/assets/data/map) project, commit `9801046af387d40cc77db4f0557c802ad8cee5b4`. Its license is included in `UPSTREAM_LICENSE.txt`; its unmodified map metadata is `upstream-map.json`. The project attributes the grid to NASA LRO LOLA PDS products [LDEM_80S_80M](https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/polar/img/ldem_80s_80m.img) and [LDEM_75S_120M](https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/polar/img/ldem_75s_120m.img); see NASA's [LOLA GDR data set description](https://pds.nasa.gov/ds-view/pds/viewProfile.jsp?dsid=LRO-L-LOLA-4-GDR-V1.0). The inner grid is a 5 × 5 block mean of 80 m data and the outer ring is an area-weighted average of 120 m data, both rounded to metres. We have **not downloaded or independently verified the original NASA rasters**, nor verified upstream preprocessing against them. The hash checks the bundled derivative's integrity, not its provenance or scientific correctness. These are gridded, interpolated historical measurements, not live terrain or an unaltered NASA product. The LOLA data do not measure every pixel. The 400 m averaging suppresses smaller features; do not confuse grid spacing with actual spatial accuracy.

## Method

The 2280 × 2280 grid is int16 elevations in metres above a 1737.4 km sphere, south-polar stereographic, south pole centered, 0°E up, 90°E right, mean-Earth / DE421 frame according to the upstream metadata. 400 m cells are sampled bilinearly, with pixel-center registration. Site latitude is planetocentric, longitude east-positive; inputs are restricted to 80–90°S, where every ray starts inside the raster. A site ground height is interpolated; observer height is **above that estimated terrain**, not above the reference sphere. A great-circle radial ray samples every 100 m from 600 m to 300 km or the raster edge, whichever comes first, for each integer azimuth; the highest point angle is computed with spherical curvature. The nearest 600 m is omitted because the grid cannot resolve it and bilinear near-field dips can produce spurious horizons. Directions between sampled azimuths are linearly interpolated; sharp terrain can be missed. The compressed raster is checked via a pinned checksum when loaded, then retained in process memory; a corrupt or missing file fails closed, rather than reverting to a flat horizon. There is no coverage or uncertainty raster and no extrapolation outside the grid.

`POST /api/terrain-screen` compares geometric Sun/Earth **centers** at requested 15/30/60-minute bin midpoints, using the terrain ground elevation plus observer height in the Step 1 geometric ephemeris. It returns the profile, per-bin directions, results, hashes and assumptions. It does not apply the main comparison's fixed clearances. An `above_sampled` result **does not establish actual visibility**: near-field obstacles, terrain beyond each ray’s sampled endpoint, averaging, DEM errors, interpolation, angular and temporal undersampling and obstructions between sampled rays may matter. A below-sampled result is also model-dependent, not a certified blockage. The Sun and Earth are not disks; there are no terrain uncertainty bounds, eclipse, antenna or operations constraints. No hardware or power model is included. Bins can miss events. This is exploratory and not for mission or safety decisions.

## Cross-checks (not an independent scientific audit)

The third-party project's independently written Dart/Python raster tests supply the `coarseHorizon` subsection of `tests/upstream_coarse_horizon_reference.json`, reproduced from its `app/test/fixtures/spice_truth.json` at the above commit under the accompanying MIT license. Our decoder matches its full-grid integer sum `-6964042991` and five reference pixel values. Site ground heights agree to within 1e-6 m for three fixture sites. In 540 common 2° azimuths for 2 m observers at (-89.4679°, -137.411°), (-85.98°, -0.26°), (-80.13°, 1.44°), mean absolute horizon differences are 0.001213°, 0.000268°, 0.000074°; maxima are 0.01112°, 0.00651°, 0.00280° respectively. The upstream calculation uses a different, variable radial sampling scheme extending to 300 km and can omit samples outside the raster; ours stops when a ray leaves the grid. Thus the differences are expected and quantify the substantial effect of assumptions, not a global accuracy bound. Both use the same 400 m derivative and related geometry; this is an independent implementation cross-check, **not** verification against NASA original data, independent observational truth, or an expert audit. Tests also exercise analytic flat-sphere and raised-observer cases, circular azimuth, missing/corrupt data and API input limits.
