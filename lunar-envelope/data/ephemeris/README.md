# 2026 lunar geometry vectors

`year_2026_ephemeris.csv` is a 2-hourly table of Moon-centred geometric Sun and Earth vectors in metres, frame `MOON_ME_DE421`, with UTC labels, from 2026-01-01 00:00 through 2027-01-01 00:00 inclusive. It is calculated ephemeris data, **not live spacecraft telemetry** or direct NASA-provided tabular measurements. Within this interval the application linearly interpolates position vectors; it does not extrapolate. Coverage outside it is rejected.

The table was retrieved from the [pinned third-party GitHub mirror](https://github.com/julianascencio/orbital-pv/tree/7c2b1a64f7d43b9662b022ac3b88351228bbd3cd/examples/lunar/_data). Its SHA-256 is `90c0d716388897af5c26ffc971d04e15817e5614ba92c4111447dca037c26ddd`, matching that mirror's [provenance](https://github.com/julianascencio/orbital-pv/blob/7c2b1a64f7d43b9662b022ac3b88351228bbd3cd/examples/lunar/_data/provenance.json). The mirror states it calculated vectors with NASA NAIF SPICE and DE421. This project does not bundle the kernels or claim a NASA endorsement. Sources: NASA [NAIF](https://naif.jpl.nasa.gov/naif/data.html), [lunar kernel documentation](https://naif.jpl.nasa.gov/naif/lunar_kernels.txt), and [JPL Horizons API](https://ssd-api.jpl.nasa.gov/doc/horizons.html).

An independent implementation check was performed with SpiceyPy/CSPICE using GitHub copies of DE421 and NAIF lunar orientation/frame/leap-second kernels at several timestamps. This is a software cross-check, not a domain-expert validation, a global uncertainty estimate, or proof of suitability for mission decisions. Five fixed topocentric azimuth/elevation cases are in `tests/test_planner.py` along with geometric invariants; the maximum difference for these cases was below 0.002 degrees. The reference DE421 kernel copy was 2048 bytes shorter and had a different SHA-256 than the source recorded by the mirror, limiting this comparison. The four SPICE kernels are not bundled. The reference check used CSPICE `azlcpo`, geometric correction `NONE`, a 1,737.4 km spherical Moon and `MOON_ME_DE421`.

The site model uses a 1,737.4 km sphere; it computes topocentric target-center azimuth/elevation with east-positive longitude. It omits terrain, slopes, lunar terrain shadows, solar-disc size, refraction, antenna, Earth obstruction beyond the sphere, atmospheric outages, and light-time/aberration. Selectable 15-, 30-, and 60-minute timeline bins use midpoint classifications, so event times and summed durations are approximate; short events can be missed. A constant clearance angle is not a terrain horizon. The +2° threshold sensitivity is not a statistically estimated uncertainty. Results must not be used for actual missions or EVA decisions.
