# Collisionless ballistic pulse

`POST /api/ballistic-pulse` computes a simultaneous, seeded, equal-weight particle pulse from one location on a 1,737.4 km reference sphere. Newtonian central acceleration is `-mu*r/|r|^3` using JPL DE440 lunar GM 4902.800118 km³/s² (https://ssd.jpl.nasa.gov/astro_par.html). Velocity Verlet uses one-second steps; outputs are recorded every 30 seconds. On first inward sphere crossing, a line-segment/sphere intersection records a return; landed particles stop. This approximation has not been independently validated or convergence-characterized over all allowed conditions.

Assumed launch distribution is a flux-weighted Maxwellian from an ideal plane: tangential velocities are independent Gaussian with standard deviation sqrt(kT/m); the outward normal speed is Rayleigh with the same scale. K, He, Na and Ar molecular masses determine mass; temperature is an input, not a measured surface temperature. A fixed random seed supports repeatability. No actual emission rate, abundance, density, re-emission, surface source mechanism, collision, radiation pressure, charge, electric field, photochemistry, terrain, Moon rotation, or other bodies are included. Treating the body-fixed launch orientation as inertial limits longer runs. Statistics are counts of equal-weight simulated particles, not a physical density estimate. The 3D sphere is an illustrative reference; altitude is exaggerated 8× and lines join 30-second frames. This is not measured exosphere data, mission planning or a validated physical forecast.

A pinned scenario is kept only in memory; the summary compares terminal returned counts and clearly displays each run's duration. The trajectory playback is visualized from backend-computed positions, not synthetic frontend motion. Controls are available through keyboard, with a numerical result if WebGL fails.
